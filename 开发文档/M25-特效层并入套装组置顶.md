# M25 - 特效层并入套装组置顶

> 状态：已合并（PR #10 → main @d37b2ca）　|　分支：`feature-fx-layer`　|　日期：2026-08-29

## 需求背景

用户把游龙特效（50105101，扁平结构）放进时装套装文件夹，期望特效作为**最顶层**
叠在 GIF 区的角色身上一起预览。实际 50105101 单独出现在左栏列表，未并入套装组。

### 根因（两层）

1. `_find_part_units` 把特效扁平文件夹直接判为独立散件单元（`units.append((None, [c]))`），
   从不进入套装判定的 `leaves`
2. 套装判定要求全部部件同一资源类别：特效（50105 前缀 → 特效类）≠ 主角类，
   即使参与也会被排除

## 设计方案

### 1. 扫描层（scanner._find_part_units）

- 扁平特效文件夹收集到独立的 `flats` 列表（不进 `leaves`）
- 套装判定只看 `leaves`（≥2 部件、跨 ≥2 ID、同类别）；阈值改为 `len(leaves) + len(flats) ≤ outfit_merge_max`
- 判定通过 → `units.append((d, leaves + flats))`：特效并入套装单元
- 判定不通过 → 叶子按散件、特效各自按散件（原行为不变）
- 特效的 `part=None` → `layer_rank(None) = len(layer_order)` → **渲染天然置顶**（高于 fills）

### 2. 查漏/配套豁免（特效无方向/动作约定）

| 位置 | 豁免 |
|------|------|
| `_check_pairing` | 跳过 flat 部件（其虚拟方向「特效」不进并集参照，避免全组误报配套异常） |
| `_finalize_group` fills 警告 | flat 部件不进 fills 缺失基准（虚拟方向不算「缺 fills」） |
| 组级缺方向/动作 | 天然无影响：虚拟方向不在 tpl.directions，动作并集由套装部件贡献 |

### 3. 渲染（app._layers_for_current）

- 组模式下 flat 部件对当前 (方向, 动作) 必然无数据 → **取自身首个 ActionData 序列**
- 特效层在任何方向/动作下都叠在角色身上（用户核心诉求）
- 帧数 = 各层 max（worker 现有语义）：角色 8 帧 + 特效 20 帧 → 合成 20 帧，
  第 9–20 帧仅特效（可完整检查特效本身）

### 4. 文案

- 左栏套装子项：flat 部件显示匹配表中文名（如 `50105101 游龙「环绕特效」`），无映射兜底「特效」
- B 区显隐 toggle 同样用中文名
- 状态栏：组含特效层时追加「特效层 N 帧·置顶」

| 文件 | 改动 |
