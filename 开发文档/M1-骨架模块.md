# M1 骨架模块 开发文档

> 分支：`feature-m1-skeleton` · 依据：01-需求方案与UI设计-v0.3.md

## 范围

拖拽 + 模板加载 + 左栏分组部件列表 + 方向/动作按钮矩阵 + 缺漏标记 + 状态栏汇总。
A/B 区为占位（M2 网格渲染、M3 动画播放接入）。

## 模块清单

| 文件 | 职责 |
|------|------|
| `templates/default.json` | 默认模板（天命装规则，含 layer_order） |
| `src/core/template.py` | Template dataclass；folder_pattern 解析（`{id}(_{part})?`，部位按长度降序匹配防 ride_front 被截断）；模板加载/保存 |
| `src/core/scanner.py` | 扫描入口 scan_root（自动判断单部件/父目录）；帧号断档检测（**min→max 区间连续**，不要求从 0001 开始）；同 ID 分组 + 配套校验（并集交集对比） |
| `src/core/namemap.py` | ID-中文名映射：自动发现 `*匹配表*.txt`、自动登记缺失 ID、内联改名回写、编码自适应（UTF-8/GBK） |
| `src/core/imageops.py` | alpha bbox / 并集 bbox / 裁剪加载（M2 接入 UI） |
| `src/ui/drop_zone.py` | 文件夹拖拽接收 |
| `src/ui/part_list.py` | QTreeWidget 按 ID 分组；过滤框；🔴 缺漏标记；部位金色高亮 |
| `src/ui/button_matrix.py` | 方向/动作行按钮全展开；missing 属性 → 暗红样式；选中金色 |
| `src/ui/grid_view.py` / `anim_view.py` | M1 占位 |
| `src/app.py` | MainWindow 装配 + 全局深色样式 + 状态栏汇总 |

## 关键决策

1. **帧号检测规则**：实测 idle=0001–0008、attack=0017–0024 跨动作连续 → `ActionData.gaps` 只查区间内断档。
2. **层级转置**：scanner 内部统一为 direction→action 矩阵；模板 hierarchy 反转时扫描后转置。
3. **配套校验**：同 ID 组内取 方向×动作 并集为参照，任一部件缺则报「配套异常」（shadow 对不上主体会被标出）。
4. **入口兼容**：`src/main.py` 同时支持 `python -m src.main` 与 PyInstaller 直接打包。
5. **中文名映射**：沿用用户手写 txt（TAB 分隔），四件套免维护——自动发现/自动登记/内联改名/热更新；实测扫描真实目录自动登记 13 个新 ID。
