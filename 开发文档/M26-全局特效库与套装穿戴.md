# M26 - 全局特效库与套装穿戴

> 状态：已合并（PR #13 → main @898cbac）　|　日期：2026-08-29
> 附：M27（默认播放动作按类型优化，主角 idle / 坐骑 ride_idle）同批合入。

## 需求背景

特效（扁平结构资源，如游龙 50105101）是**通用资源**：所有主角套装都可以穿戴同一套特效。

当前 M25 的归属规则是**按物理位置**——只有和套装在**同一个父文件夹**下的特效才会自动
并入套装组。这导致用户必须把特效**复制**到每个套装目录里才能预览，特效一多就产生大量
冗余副本，改一个特效要同步改 N 份。

用户诉求：把特效移到**最外层独立文件夹**（如 `特效库/`），作为全局共享资源；
预览任意套装时，从库里**挑一个特效穿上**。

### 现状局限

| 问题 | 说明 |
|------|------|
| 特效必须复制进套装目录 | 冗余副本，维护成本随套装数线性增长 |
| 特效重复出现在左栏 | 每个套装组都带一份同名特效子项 |
| 偏移要重复调 | 同一特效在不同套装里要各调一次偏移 |

## 设计方案

### 1. 扫描层：全局特效库

`ScanResult` 新增 `fx_library: list[PartData]`——**所有** `is_flat` 的特效，
无论物理位置（套装目录内 / 最外层独立文件夹 / 任何深度），统一收进全局库。

```python
# scan_root 末尾
result.fx_library = [p for p in result.parts if p.is_flat]
```

**无需新增目录约定**：特效靠模板 `categories.flat` 规则（`id_prefix: 50105` + 扁平结构）
自动识别，放在任何位置都能进库。

### 2. UI：显示层面板加「穿戴特效」下拉框

B 区右上角「显示层」面板（`PartToggles`）标题下加一个下拉框：

- 选项：`无` + 特效库全部特效（显示匹配表中文名，如「游龙」，无映射兜底文件夹名）
- 仅套装组视图显示；单部件视图隐藏
- 选择后发出 `fx_dressed(key)` 信号，`""` 表示不穿戴

> 选型理由：穿戴与「显示层 / 偏移微调」同属一个面板，选完特效可直接按 Ctrl+方向键
> 微调，操作路径最短。

### 3. 状态：按套装记忆穿戴选择

- `self._dressed_fx: dict[str, str]` = {套装 key: 特效 key}
- QSettings 持久化：`layering/dressed_fx/{group_key}` = 特效 key（`""` = 不穿戴）
- 切换套装时自动恢复该套装上次穿的特效

### 4. 合成：穿戴特效追加为顶层 flat 层

`_layers_for_current` 在组模式遍历完 `group.parts` 后追加：

```python
dressed = self._dressed_fx.get(self._group.key, "")
fx = self._fx_by_key.get(dressed)
# 已在组内的特效不重复追加（兼容未迁移的目录）
if fx is not None and fx.name not in {p.name for p in self._group.parts}:
    ad = next((a for col in fx.matrix.values() for a in col.values()), None)
    if ad and ad.frames:
        layers.append(ad.frames); flat_mask.append(True)
```

特效 `part=None` → `layer_rank` 最大 → 天然渲染置顶（复用 M25 既有语义）。

### 5. 顺序一致性（关键）

穿戴特效是**追加**的层，`part_keys` 必须与之严格同序，否则 Ctrl+方向键微调会
作用到错误的层。改造 `_layers_for_current` **同时返回 part_keys**，
由它内部保证顺序，避免 app.py 与合成链各算一份导致错位。

```python
def _layers_for_current(self) -> tuple[
    list[list[Path]],          # layers
    list[bool],                # flat_mask
    dict[int, tuple[int,int]], # fx_offsets
    list[str],                 # part_keys（与 layers 同序）
]
```

### 6. 偏移记忆：按特效名，跨套装复用

`fx_offsets` 用**特效文件夹名**作 key（如 `50105101`），而非套装相关 key。
→ 同一特效调一次偏移，所有套装复用，契合「通用资源」语义。

## 兼容性

| 场景 | 行为 |
|------|------|
| 特效仍在套装目录内（未迁移） | 保持 M25 自动并入；下拉框也能选它，但检测到已在组内则**不重复追加** |
| 特效已移到外层 | 自动进全局库；套装预览时手动穿戴 |
| 单部件视图 | 无套装 key，下拉框隐藏，行为同现状 |

## 测试点

1. 特效放最外层独立文件夹 → 进全局库，下拉框可见
2. 选套装 A 穿「游龙」→ 顶层叠加，播放正常
3. 切到套装 B → 恢复 B 自己的穿戴选择（若有）
4. 特效仍在套装目录内 → 不重复追加（只叠一层）
5. Ctrl+方向键微调穿戴的特效 → 作用到正确层，偏移按特效名保存
6. 换套装穿同一特效 → 偏移复用（不需重调）
7. 单部件视图 → 下拉框隐藏
