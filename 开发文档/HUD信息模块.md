# HUD 信息模块（M32）

## 需求背景

美术核对序列帧资源时，需要一眼看到**当前资源（含套装）的完整帧数账目**：

- 每个「方向-动作」组合：帧数 + 帧号范围
- 一个 ID 的总帧数

此前这些信息散落在状态栏（只显示当前组合）和按钮缺失标记（不显示数量），
缺少一个全局账目视图。

## 方案（2026-09-10 确认）

三个决策（用户拍板）：

| 决策项 | 结论 |
|--------|------|
| 展示方案 | **A + B 叠加**：B区画布 HUD 浮层 + 方向/动作按钮帧数角标 |
| 套装数量口径 | **主件为准 + 不一致标 ⚠**（body 优先，缺 body 取首个主体部件；组内其他部件帧数不同的组合标 ⚠，顺带成为配套校验的可视化） |
| 默认开关 | **默认开**，QSettings 记忆（`hud/visible`） |

## 数据层：src/core/stats.py

全部从扫描结果聚合，**零新增 IO**（数据在 `scan_root` 时已读入内存）：

| 统计项 | 来源 |
|--------|------|
| 单组合帧数/范围/断档 | `ActionData.count / numbers[0] / numbers[-1] / gaps` |
| 单部件总帧数 | 该部件全部 (方向,动作) count 求和 → `part_total()` |
| 套装组组合行 | 组内非特效部件的 (方向,动作) **并集**，每行取主件（缺则首个有该组合的部件）帧数 → `group_combos()` |
| 特效行 | 扁平部件各自成行（虚拟方向「特效」+ 序列前缀），帧号不补零 |
| 帧 ID 小计 | `group_combos()` 返回 `{部件标签: 总帧数}`，显示在 HUD tooltip |

排序：按模板 `directions` / `actions` 顺序，模板外的组合追加在末尾（字母序）。

## UI 层

### HUD 浮层（src/ui/hud_panel.py）

- 挂载方式与 PartToggles 一致：`stack_host` 手动定位悬浮子控件（不进布局，
  其余区域鼠标事件不受影响），位置**右下角**——右上角已被组视图的
  逐部件显隐 toggle / 穿戴下拉框占用（M26/M28）。
- 半透明深色卡片（`rgba(42,46,51,0.92)`），金色标题、米白正文、红 ⚠，与全局
  Modern Dark Flat 主题一致；字号 ≥ 14px（用户视力适配）。
- 行数过多时内部 QScrollArea 滚动，高度不超过宿主 75%。
- 当前选中 (方向,动作) 的行金色高亮；断档/帧数不一致的行红字 ⚠。
- tooltip：套装模式下显示各部件 ID 帧数小计。

### 按钮角标（src/ui/button_matrix.py）

- `BadgeButton(QPushButton)`：右上角小圆角角标（金色帧数 / 红色异常）。
- **只加在动作按钮**上：显示当前方向下该动作的帧数（与 HUD 同口径，套装取主件）。
  断档或帧数不一致 → 红色角标。
- 方向按钮不加角标（方向无"帧数"语义，避免信息噪声）。

## 刷新链路

`_after_matrix_change()` → `app._update_hud()` → `anim_view.update_hud(HudStats)`
与状态栏同一刷新点：切换资源 / 方向 / 动作 / 显隐 toggle / 穿戴 时即时更新，
纯内存计算毫秒级。

## 开关与持久化

- B区控制条新增「📊 HUD」checkable 按钮（与 棋盘格/循环 同级）。
- QSettings `hud/visible`（默认 True），重启恢复。
