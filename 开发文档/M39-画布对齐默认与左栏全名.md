# M39：画布对齐默认开启 + 左栏自适应加宽（完整展示名字）

> 日期：2026-09-29
> 状态：开发中（PR #21）
> 分支：`feature/m37-look-combine`

## 背景（用户反馈）

1. 画布对齐（M34）符合「部件按原始渲染画布对齐」的直觉，希望**默认开启**。
2. 左栏列表名字被截断（如「501031001 · 昆仑剑侠…」），希望**默认展示完整名字**。

## 方案

- `app.py`：`display/canvas_align` QSettings 默认值 False → True。
  （已记忆为「关」的机器点一次「画布对齐」按钮即长期记忆为开。）
- `PartList.preferred_width()`：按当前最长条目（组头 + 子项）以控件实际字体
  测量文本宽度 + 内边距，夹在 [220, 480] 区间。
- `app._on_folder_dropped(..., auto=False)`：加载后左栏**只加宽不收窄**到理想宽度；
  `auto=True`（M24 自动重扫）不触发——不覆盖用户手动拖动的宽度；显式拖入 /
  启动恢复时生效。splitter 尺寸照旧在关闭时持久化。
