## 二、功能

- 选中**单部件**：A区显示该部件选中方向×动作的帧，100% 原尺寸、透明无边框、并集 bbox 对齐
- 选中**同ID组**（点左栏组头）：组内所有部件按 `layer_order` 从下到上叠合（shadow 固定最底），用于检查资源配套是否正确
- 解码 / 合成在 `QThread` 后台（`_GridWorker`），不阻塞 UI

## 三、关键实现

### 3.1 并集 bbox（统一窗口）

- 网格用「全序列并集 bbox」：所有帧 alpha 有效像素的 min/max 并集
- 每帧按自身 bbox 裁剪后，对齐到统一窗口 → 网格每格尺寸一致、帧间不抖动
- 叠层各层同样共享该并集窗口（v0.3 定稿）

### 3.2 叠层合成 `composite_layers(frame_paths, bbox)`

```
for 每层（从底到上）:
    lb = frame_bbox(层帧)            # 该层单帧有效像素 bbox
    if lb is None: continue          # 全透明跳过
    crop = 层帧.crop(lb)
    offset = (lb.left - bbox.left, lb.top - bbox.top)
    canvas.alpha_composite(crop, offset)
```

- `frame_paths` 已按 `layer_order` 排序（`scanner._group_parts` 用 `tpl.layer_rank` 排，shadow 在前 = 最底）
- 元素为 `None` 表示该层此帧缺失 → 跳过（叠层此处透明），自然暴露配套异常

### 3.3 组 / 单部件互斥上下文

- `MainWindow._part` / `_group` 互斥
- 左栏点组头 → `group_selected(res_id)` → 找 `IdGroup` → `matrix.show_group()` + `_show_grid()`
- 左栏点子项 → `part_selected(PartData)` → `matrix.show_part()` + `_show_grid()`
- `_show_grid()` 按当前 (组/部件) + 当前 (方向,动作) 计算各层帧序列 `list[list[Path]]` 交给 `GridView.show_sequence`

### 3.4 按钮矩阵组视图 `show_group`

- 按钮基于组内所有部件的并集 (方向,动作)
- 缺失标记 = 模板要求但**组内无任何部件拥有**的组合（快速看出这个 ID 整体缺什么）

## 五、已知约束

- 解码逐帧，大目录（164 部件）仅在选择具体 (ID组/部件, 方向, 动作) 时解码该组合（通常 <100 帧），未做全量预解码
- 组模式帧数对齐按**索引**：各层第 i 帧叠合；配套异常（某层帧少）会表现为后几帧缺层
- `GUI SMOKE OK` 在 offscreen 下退出码偶发非 0（Qt 析构所致），不影响功能；本机实测为最终判定
