三、同 ID 叠层设计（v0.3 核心新增）

要点规则
触发条件左栏点击 ID 组头 → 自动按 layer_order 叠合同 ID 全部部件；点击单部件 → 仅显示该部件
叠放顺序模板 layer_order 定义，数组前 = 越底层；shadow 固定最底层
对齐方式参与层共享同一并集 bbox 窗口，各层按同一窗口裁剪后叠加，不错位
作用范围A 区网格与 B 区动画同步叠层；仅限同 ID，不做跨 ID 自由组合
配套校验同 ID 各部件 方向×动作 矩阵交集对比：主体有的动作 shadow 缺 → 状态栏标「配套异常」

五、中文名映射（左栏显示「502019 · 杜如晦」）

沿用现有 ID-角色-名字匹配表.txt（TAB 分隔、# 注释），四件套把维护成本降到最低：

机制说明
自动发现拖入目录及父级自动找 *匹配表*.txt，无需配置路径
自动登记扫描后表里没有的 ID 自动追加 ID⇥（待命名）（带日期分节）。维护 = 补空，不再手写整张表
内联改名左栏组头 F2 / 单击选中态直接改中文名，回车写回 txt（保留注释与分组结构）
热更新txt 被外部编辑后自动重载刷新列表
✅ 已随 M1 实现并实测：扫描「角色输出图」（164 部件 / 157 ID 组）自动登记 13 个新 ID；查找优先级 完整文件夹名 → 纯 ID；编码自适应 UTF-8/GBK；部位中文名（头发/影子…）自动回填。
