# M3 · B 区动画播放模块

> 状态：✅ 已完成（2026-08-19）· 配套 PR #3
> 关联：开发文档/01-需求方案与UI设计-v0.3.md（第 3.3 节叠层、F6 棋盘格背景）

## 一、模块归属

| 文件 | 职责 |
|------|------|
| `src/ui/anim_view.py` | B 区 GIF 动画播放控件（播放/暂停/FPS/步进/循环/棋盘格） |
| `src/ui/worker.py` | 后台解码 worker（grid_view / anim_view 共用） |
| `src/ui/grid_view.py` | A 区点击某帧 → `frame_clicked(index)` |
| `src/app.py` | `_show_anim()` / `_on_grid_frame_clicked()` A/B 区联动调度 |

## 二、功能

- **自动同步**：切换方向/动作/部件/组时，B 区与 A 区同步加载同一组帧
- **播放控制**：播放/暂停、FPS 滑杆 1–60、上一帧/下一帧、循环开关
- **棋盘格背景**：默认透明融入 UI，勾选后显示棋盘格，方便检查 alpha 毛边
- **A→B 联动**：点击 A 区任意帧，B 区跳转并暂停，方便逐帧对照
- **100% 原尺寸、并集 bbox 对齐、无边框**，与 A 区一致

## 三、关键实现

### 3.1 共用后台解码 `DecodeWorker`

为避免 grid / anim 重复写 worker，M3 把解码逻辑抽到 `src/ui/worker.py`：

```python
DecodeWorker(layers: list[list[Path]])
  → frame_ready(idx, PIL.Image, label)
  → finished(total)
```

- 子线程只做 PIL 解码 + alpha 合成
- `QPixmap` 在主线程的 `_on_frame` 回调里创建（`QPixmap` 不可跨线程）

### 3.2 `AnimView` 状态机

| 状态 | 行为 |
|------|------|
| 无帧 | 画布空白，播放按钮不可用 |
| 解码中 | 标题显示「解码中…」，播放按钮未按下 |
| 解码完成 | 自动开始播放（循环默认开启），FPS=12 |
| 用户点击 A 区帧 | `goto_frame(idx)` → 暂停 → 显示该帧 |
| 点击上一帧/下一帧 | 暂停并移动一帧 |

### 3.3 棋盘格背景 `_AnimCanvas`

- 继承 `QLabel`，重写 `paintEvent`
- 未勾选棋盘格：先画透明背景，再居中画当前帧
- 勾选棋盘格：先填充 16×16 灰白相间方块，再居中画帧

### 3.4 A/B 联动

`app.py` 中：

```python
self.grid_view.frame_clicked.connect(self._on_grid_frame_clicked)

def _on_grid_frame_clicked(self, idx: int) -> None:
    self.anim_view.goto_frame(idx)

def _after_matrix_change(self) -> None:
    self._show_grid()
    self._show_anim()
    self._refresh_status()
```

`_layers_for_current()` 统一计算当前 (组/部件) + (方向,动作) 的帧序列，A/B 区共享，避免两边解码结果不一致。

## 五、已知约束

- 动画默认 FPS=12，与常见 2D 序列帧预览习惯一致
- 循环默认开启；播放到末尾不循环时自动暂停
- 解码仍在后台线程，但 B 区在加载完成前画布为空，未做占位 loading 图（v0.4 可选优化）
