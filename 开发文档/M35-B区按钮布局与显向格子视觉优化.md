# M35 · B 区按钮布局与显向格子视觉优化

> 状态：✅ 开发完成（2026-09-29）· 分支 `feature/b-toolbar-overlay-visual`
> 模块归属：`src/ui/anim_view.py`（M3 动画播放模块 / M8 显向 overlay）
> 验证：`tests/test_m35_b_toolbar_overlay.py` ALL PASS；M8/M32/M34/smoke_gui 回归通过

## 一、需求背景（用户反馈 2026-09-29）

1. **工具栏遮挡 B 区视觉区**：方向/动作按钮矩阵以悬浮层（QStackedLayout StackAll）
   叠在画布左侧（宽 96px），压住画布左侧 1/3 的显向格子（NW/W/SW 被遮挡），
   角色移到左侧时也会被按钮挡住。
2. **8 个显向格子太显眼**：hover 时整面格子背景/边框/文字过重，希望「淡淡的、
   能区分和知道可点击即可」；且**当前方向**与**鼠标悬浮**的高亮颜色相同（都是金色），
   无法一眼区分。

## 二、方案

### 2.1 按钮矩阵改回独立列（消除遮挡）

- 布局从 `QStackedLayout(StackAll)` 悬浮改回 `QHBoxLayout`：
  左 = 按钮矩阵列（固定宽 96px，顶部对齐）| 右 = canvas host（铺满）
- 与 M8 文档原始设计一致；画布不再被任何控件遮挡
- 显示层 toggles / HUD 面板改挂 canvas host（画布区），右上/右下定位
  不再需要 `LEFT_PANEL_WIDTH` 水平偏移

### 2.2 显向 overlay 视觉弱化 + 双色区分

| 状态 | 旧版 | 新版 |
|------|------|------|
| 其他格子 | 灰底 α18 + 虚线 α110 + 字 α160 | 灰底 α10 + 虚线 α40（不可用 α22）+ 字 α120（不可用 α90） |
| 当前方向 | 金底 α40 + 金实线 α200 宽2 + 米白字 | 金底 α30 + 金实线 α140 宽1 + **金字** |
| 悬浮/拖拽 | 金底 α70 + 金实线 α200 宽2 | **米白**底 α38 + 米白实线 α200 宽2 + 米白字 |

- 语义约定：**金色 = 当前方向**（与按钮矩阵选中态同色系）、**米白 = 鼠标指向**（悬浮反馈）
- 整体更透明，仅提供「可点击」暗示，不抢动画主体的视觉焦点

## 四、M35.1 根因备忘（按钮列塌缩）

**症状**：独立运行 AnimView 正常；MainWindow 中按钮列只显示「方向」标题 + 第一个按钮 E。

**数据**：容器/viewport 高 52（正常应 ~625）；`QScrollArea.sizeHint()` 在主窗口环境返回 52
（独立窗口返回 432），`Qt.AlignTop` 对齐让容器高度退化为该 sizeHint → 塌缩。

**修复**：`body.addWidget(self._matrix_container)`（无对齐参数）——HBox 直接拉伸容器到
整列高度，不再依赖 sizeHint；按钮内部由 `_MatrixScrollArea`（widgetResizable + AsNeeded
滚动）管理，超出高度滚动条接管。

**教训**：QScrollArea 的 sizeHint 受环境影响不稳定，承载它的容器高度必须由布局直接拉伸，
不能用对齐参数退化为 sizeHint 驱动。
