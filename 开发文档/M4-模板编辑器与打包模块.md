## 一、模块归属

| 文件 | 职责 |
|------|------|
| `src/ui/template_editor.py` | 模板编辑器对话框（表单 + 字符串列表编辑） |
| `src/app.py` | 顶栏「编辑/新建」按钮接线、保存后刷新模板与当前扫描 |
| `FrameQuickView.spec` | PyInstaller spec（onefile，自动收集 src 子模块 + templates 数据） |
| `scripts/build.py` | 打包脚本：清理 → pyinstaller → 复制到 `releases/vX.Y.Z_YYYYMMDD/` |
| `tests/smoke_template.py` | 模板 save/load/parse 冒烟测试 |

## 二、功能

### 2.1 模板编辑器

- 编辑当前模板：顶栏「✎ 编辑」
- 新建模板：顶栏「＋ 新建」
- 可编辑字段：
  - 名称、folder_pattern、frame_pattern、扩展名
  - 部位 / 方向 / 动作：带 + / - / ↑ / ↓ 的列表编辑器
  - 层级顺序：方向→动作 或 动作→方向
  - 叠层顺序 `layer_order`：越靠前越底层
- 保存为 JSON 到 `templates/{名称}.json`
- 保存后自动重新加载模板列表，并重新扫描当前目录

### 2.2 打包发布

- 命令：`.venv/Scripts/python.exe scripts/build.py onefile`
- 输出：
  ```
  releases/v0.1.0_20260819/
  ├── MY-FrameQuickView.exe
  └── README.txt
  ```
- 当前产物大小：约 54 MB（PySide6 + Pillow + numpy 单文件）

## 三、关键实现

### 3.1 `_StringListEditor`

通用字符串列表编辑组件，被部位/方向/动作/layer_order 复用：
- `+` 添加并进入编辑态
- `-` 删除选中项
- `↑ / ↓` 调整顺序

### 3.2 PyInstaller 自动收集模块

spec 中遍历 `src/` 下所有 `.py` 文件生成 hiddenimports，避免手动维护：

```python
hidden = []
for py in src_dir.rglob("*.py"):
    rel = py.relative_to(project_root)
    mod = str(rel.with_suffix("")).replace("\\", ".").replace("/", ".")
    ...
```

### 3.3 templates 数据文件打包

spec 中把 `templates/` 目录作为 data 包含：

```python
datas=[(str(templates_dir), "templates")]
```

运行时 `src/core/template.py` 的 `templates_dir()` 优先定位 exe/脚本旁目录，PyInstaller 会自动映射到 `_MEIPASS`。
