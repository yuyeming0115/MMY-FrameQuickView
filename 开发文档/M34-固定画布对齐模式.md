# M34 · 固定画布对齐模式

> 状态：**待合并（PR 待创建）** · 2026-09-28 · 分支 `feature/canvas-align-mode`

## 一、需求背景

用户实测反馈（2026-09-28）：同一角色「有武器 vs 无武器」两个视图，角色位置看起来没对齐。

### 根因（不是资源错位）

A/B 区默认显示 = 「内容并集 bbox 裁剪 + 普通层组中心对齐画布中心」两重内容自适应：

1. **并集 bbox 窗口**（`imageops.union_bbox`）：武器向左下延伸把窗口撑大、边界移动；
2. **锚点居中**（`DecodeWorker.anchor`）：普通层组 union bbox 中心被平移到合成画布中心，
   武器把普通层组中心拉偏 → 角色身体被推离画布中心。

两个视图的窗口与锚点都不同 → 自适应缩放后角色视觉位置漂移。同一视图内的叠层
（影子/身体/头发）按原始渲染画布像素坐标直接合成，组内永远像素级对齐；
只有**跨视图**比较才会看到漂移。

## 二、方案：固定画布对齐模式

顶栏新增 checkable 按钮「📐 画布对齐」（默认关，QSettings `display/canvas_align` 记忆），
全局同时作用于 A/B 区：

| 维度 | 默认（并集 bbox） | 画布对齐（M34） |
|------|------------------|----------------|
| 裁剪窗口 | 内容 alpha 并集 bbox | 原始渲染画布 `(0, 0, W, H)` |
| 普通层位置 | 组中心平移到画布中心 | **原始画布坐标，不平移** |
| 特效层 | 层 union bbox 整体居中 + 用户微调 | 不变（仍居中 + 微调） |
| 跨视图角色位置 | 随内容漂移 | **纹丝不动**（画布即绝对坐标） |

画布尺寸 W/H = 普通层帧尺寸取 max（无普通层帧时退化用全部帧，纯特效组行为≈原模式）。

### 实现要点

- `imageops.frame_info(path)`：一次解码同时返回 (bbox, 画布尺寸)，供 worker 建双缓存
  （`frame_bbox` 保留为兼容包装）
- `DecodeWorker` 新参 `canvas_align`：为 True 时 `bbox=(0,0,W,H)`、
  `anchor=(W//2, H//2)` → `composite_layers` 的 shift=0，**composite_layers 零改动**
- `grid_view` / `anim_view` 的 `show_sequence` 新参 `canvas_align` 并存成员供标题文案
- `app.py` 顶栏按钮，切换后重调 `_show_grid()` / `_show_anim()`

### 边界说明

- 各视图**画布尺寸一致**时对齐严格成立（同一次渲染输出画布固定）；画布尺寸不同的
  资源（如不同 ID 输出规格不同）在自适应缩放下仍可能视觉大小不同——画布已是能做到的绝对基准
- 前提假设：渲染输出中角色大致居中于画布（特效/穿戴翅膀仍按画布中心居中摆放）
- 画布模式留白较多（画布通常远大于角色），配合 A 区「自适应」模式使用
