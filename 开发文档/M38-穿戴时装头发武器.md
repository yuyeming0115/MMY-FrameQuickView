# M38：穿戴时装/头发/武器（跨 ID 手动搭配）

> 日期：2026-09-29
> 状态：开发中（与 M37 同分支，PR #21）
> 分支：`feature/m37-look-combine`

## 1. 背景

M37 的形象组合靠**中文名前缀精确匹配**（去尾部类型词后一致），是「1 组对 1 组」的。
但一把 0 阶武器逻辑上属于同武器类型的**所有**时装形象：

```
昆仑剑侠〔剑〕武器0阶  ── 应可搭配 ──▶  昆仑剑侠〔剑〕职业0阶
                                      天命·男〔剑〕时装 / 发
                                      伏羲·男〔剑〕时装 / 发
                                      归元·男〔剑〕时装 / 发 …
```

一把武器只有一个名字，改任何名字都无法同时进入多个前缀组——**1:N 关系前缀匹配
天然做不到**。用户确认采用「穿戴下拉」方案（零命名约束、选择按组记忆）。

## 2. 方案

显示层面板新增三个穿戴下拉（复用 M26/M28 穿戴机制）：

- **穿戴时装 / 穿戴头发 / 穿戴武器**：当前显示（含 M37 形象组合）**缺哪类才显示
  哪类**的下拉框；选项 = 所有拥有该部位的常规组（排除套装组/世界BOSS变体/特效），
  显示名 = 匹配表中文名。
- 选中即把该形象组的全部渲染部件（含其影子，layer_order 内部排序影子最底）
  叠加到当前预览；取帧/对齐方式同穿戴翅膀（按 (方向,动作)，居中对齐）。
- **选择按当前组 key 记忆**（QSettings `layering/dressed_body/hair/weapon`），
  切换组自动恢复；选「无」= 脱下。
- 状态栏提示「👤 组名 穿戴时装：xxx」。
- 空帧抽样目标同步包含穿戴部件（与实际显示口径一致）。

与 M37 的关系：形象组合（自动）+ 穿戴（手动）叠加生效；同一部位已有（自动带出）
则对应下拉隐藏、记忆的穿戴跳过，不会重复叠加。

## 4. 验收标准

1. 选中「天命·男〔剑〕时装」（形象组合已带头发）→ 仅「穿戴武器」下拉可见，
   选项含全部武器组；选「昆仑剑侠〔剑〕武器0阶」→ 画布 5 层（身体影子+身体+头发+武器影子+武器）；
2. 选中武器组 → 可反向穿戴时装/头发；「穿戴武器」隐藏；
3. 切组再切回，穿戴记忆恢复；选「无」脱下还原；
4. 全量既有测试通过。

## 变更记录

- 2026-09-29：创建方案文档并实现完成；test_m38 通过，全量 34 套测试通过。
- 2026-09-29：**修复穿戴武器不对齐（脱手）bug**。原因：穿戴层误用特效层语义
  （flat_mask=True，按层自身并集框居中）——这些部件与主体出自同一张渲染画布
  （875×875），原始画布坐标才是对齐基准，武器被强制居中而脱手，画布对齐开关
  均无法补救。修复：`_append_dressed_look` 改为普通层语义（flat=False，保留
  原始画布坐标，参与并集 bbox 与跨帧锚点）；并集 bbox / 画布对齐两种模式均已
  实测对齐（真实资源离屏渲染验证）。test_m38 增加 flat=False 断言。
